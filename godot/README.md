# Вспышка — прототип на Godot 4

Отдельный от браузерной версии прототип, чтобы сравнить движки.

## Как запустить

1. Открой Godot 4.3 или новее.
2. В менеджере проектов нажми «Импорт», выбери файл `project.godot` в этой папке.
3. Нажми F5 (или кнопку «Запустить проект»).

## Что внутри

- `scripts/main.gd` — сборка сцены кодом: окружение, свет, город из кварталов (башни, многоэтажки, частный сектор, парки), люди, интерфейс, инструменты.
- `scripts/sim.gd` — симуляция: жители, полиция, зомби, укусы и обращение, паника, взрывы с разлётом тел.
- `scripts/camera.gd` — орбитальная камера: правая кнопка вращает, колесо приближает, WASD двигает, средняя кнопка тащит.

Инструменты: Зомби, Орда, Заразить, Полиция, Взрыв. Пробел — пауза, Esc — режим наблюдения.
